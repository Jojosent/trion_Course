# 🎓 Trion Academy — Образовательная Платформа Онлайн-Курсов

Современная образовательная веб-платформа для обучения веб-разработке и другим IT-дисциплинам, написанная на **Node.js** с фирменным стилем **White, Orange (#FF6600), Black** и интеллектуальной защитой видеоконтента.

---

## ⚡ Ключевые возможности

### 1. 🛡️ Защищенный интерактивный видеоплеер (Anti-Skip & Anti-Download)
* **Хостинг через YouTube Unlisted**: преподаватель загружает видео на YouTube как «Доступ по ссылке» (включая YouTube Shorts, например `https://youtube.com/shorts/vLpVCVKySCE?feature=share`), и вставляет ссылку в админке или кабинете учителя.
* **Защита от скачивания и перехода**:
  * Верхний защитный экран блокирует заголовок YouTube, кнопку «Поделиться» и «Смотреть позже».
  * Нижний правый экран перекрывает логотип YouTube.
  * Прямой клик по видео перехватывается прозрачным оверлеем для управления воспроизведением (`Play / Pause`), не давая перейти на YouTube.
  * Запрет контекстного меню правой кнопки мыши (`contextmenu`).
* **Строгая блокировка перемотки вперед**:
  * Ползунок времени отключен для перемотки вперед (Non-clickable / No forward scrub).
  * Реализована специальная кнопка **`- 5 сек`** (быстрый откат назад для повторения непонятного материала).
  * Фоновый сторожевой таймер отслеживает попытки скачка вперед и мгновенно сбрасывает воспроизведение назад.
  * Блокировка клавиатурных клавиш ускорения и перемотки вперед (`ArrowRight`, `L`).
* **Автоматическая фиксация прогресса**:
  * Прогресс сохраняется в базу данных.
  * При просмотре более 85% видео урок автоматически помечается как пройденный.

### 2. 📚 Интерактивные теоретические конспекты
* Поддержка Markdown с автоматической генерацией чистой типографики.
* Подсветка синтаксиса блоков кода (JavaScript, Node.js, HTML, CSS, SQL).
* Кнопка ручного закрепления теории.

### 3. 👥 3 Роли пользователей
1. **`student` (Ученик)**:
   * Просмотр курсов, изучение теоретических материалов.
   * Просмотр защищенных видеоуроков с честным трекингом прогресса.
2. **`teacher` (Преподаватель)**:
   * Кабинет преподавателя (`/teacher`).
   * Создание и редактирование курсов.
   * Добавление видеоуроков по ссылке с YouTube и оформление конспектов.
3. **`admin` (Главный администратор)**:
   * **Прямой вход по адресу `/admin`** (в публичном интерфейсе ссылка скрыта, как и требовалось).
   * Просмотр статистики всей платформы.
   * Управление ролями (переключение любого пользователя между `student`, `teacher`, `admin`).
   * Модерация и удаление курсов.

### 4. 🔥 База данных: Firebase Firestore + надежный Local Fallback
* Полная поддержка **Google Firebase Admin SDK & Cloud Firestore**.
* Если файл конфигурации Firebase еще не добавлен, сервер **автоматически использует встроенное локальное хранилище `data/db.json`**, обеспечивая мгновенный запуск без ошибок!

## 🔥 Подключение реального Firebase (Cloud Firestore)

Чтобы переключить хранилище на ваш облачный проект Firebase:
1. Зайдите в [Firebase Console](https://console.firebase.google.com/) и создайте проект.
2. Включите **Cloud Firestore** в режиме Production или Test.
3. Перейдите в **Project Settings (Настройки проекта)** -> вкладка **Service Accounts (Сервисные аккаунты)**.
4. Нажмите кнопку **«Generate new private key» (Создать закрытый ключ)**.
5. Скачанный JSON-файл переименуйте в `serviceAccountKey.json` и положите в корень проекта `trion_trion_Course/serviceAccountKey.json`.
6. Перезапустите `node server.js` — в консоли появится сообщение:
   \`\`\`
   🔥 [Firebase] Успешно подключено к Firestore Cloud Database!
   \`\`\`
